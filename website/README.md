# 웹사이트 기본 골격

의존성 없는 정적 HTML/CSS/JS 골격입니다. `index.html`을 브라우저로 바로 열면 됩니다.

## 구조
- `index.html`: 헤더·내비게이션, 히어로, 소개, 특징, 갤러리, 문의, 푸터
- `css/style.css`: 맨 위 `:root`의 CSS 변수에서 색·폰트·간격을 한 번에 바꿀 수 있습니다
- `js/main.js`: 모바일 메뉴 토글, 푸터 연도
- `assets/`: 이미지 등을 넣을 폴더
