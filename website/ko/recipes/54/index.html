RECIPE 54 · 마케팅/브랜딩

글로벌 타겟을 겨냥한 영문/다국어 해외 마케팅 캠페인 현지화

버튼 3개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 국내 캠페인 기획안

순서

  1. 버튼 26 · 캠페인 기획

    마케팅 캠페인 아이디어를 기획하겠습니다.

    프롬프트 보기
    마케팅 캠페인 아이디어를 기획하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을, 누구에게 알리는 캠페인인가요?
2) 예산 규모는? (보기: 거의 없음 / 소규모 / 넉넉함, 추천: 소규모)
3) 주요 채널은? (보기: SNS / 오프라인 / 검색·광고 / 알아서, 추천: 알아서)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
캠페인 안 2~3개를 씁니다. 각각 콘셉트 / 핵심 메시지 / 채널과 실행 방법 / 고객이 참여하게 만드는 장치 / 성과 지표. 예산 수준에 맞는 안을 1개 추천합니다.

  2. 버튼 50 · 글로벌 현지화

    해외 시장이나 다른 문화에 맞게 바꾸겠습니다.

    프롬프트 보기
    해외 시장이나 다른 문화에 맞게 바꾸겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 현지화하나요? 글이나 계획을 붙여 넣어 주세요.
2) 대상 국가나 지역은? (보기: 미국 / 일본 / 동남아 / 유럽 / 기타, 추천: 미국)
3) 결과물은? (보기: 현지 언어로 번역+수정 / 한국어로 수정 방향만, 추천: 현지 언어로 번역+수정)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
문화, 관습, 법·규제 차이 중 영향이 큰 것을 짚고, 고친 버전을 보여 줍니다. 단순 번역이 아니라 표현, 예시, 단위, 날짜 형식까지 맞춥니다.

    상품·서비스 소개 페이지(랜딩페이지) 구성과 문구를 쓰겠습니다.

    상품·서비스 소개 페이지(랜딩페이지) 구성과 문구를 쓰겠습니다.

1) 무엇을, 누구에게 파나요? 특징과 가격을 아는 만큼 알려 주세요.
2) 원하는 행동은? (보기: 구매 / 무료 체험 신청 / 상담 신청, 추천: 상담 신청)
3) 고객 후기나 실적이 있나요? (보기: 있음(붙여 넣기) / 없음, 추천: 없음)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
섹션 순서대로 씁니다: 첫 화면(메인 문구와 버튼) / 고객의 문제 / 해결책 / 핵심 장점 3개 / 믿을 근거(후기, 실적) / 자주 묻는 질문 / 마지막 버튼. 후기나 실적은 지어내지 말고, 없으면 [후기 자리]로 둡니다.
