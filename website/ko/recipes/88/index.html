  1. 버튼 35 · MECE 구조화

    내용을 겹치거나 빠지는 것 없이(MECE) 다시 묶겠습니다.

    프롬프트 보기
    내용을 겹치거나 빠지는 것 없이(MECE) 다시 묶겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 정리할 내용을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 나누는 기준 선호가 있나요? (보기: 주제별 / 시간순 / 담당별 / 알아서, 추천: 알아서)
3) 결과 형태는? (보기: 번호 목록 / 표 / 트리 구조, 추천: 번호 목록)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
겹치는 항목은 합치고 빠진 항목은 [추가 제안]으로 표시해 다시 분류합니다. 위계가 보이게 번호를 붙이고, 어떤 기준으로 나눴는지 한 줄로 밝힙니다. 내용 자체는 바꾸지 않습니다.

2) 우리가 가진 데이터가 있나요? (보기: 있음(붙여 넣기) / 없음, 추천: 없음)
3) 누가 읽나요? (보기: 내부 상사 / 임원 / 외부 고객·투자자, 추천: 내부 상사)
