프로덕트 개인정보보호·약관·법적 규제 준수 점검표

버튼 3개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

1) 무엇을 만들려고 하나요? 기능과 목적을 알려 주세요.
2) 누가 쓰나요? (보기: 고객 / 사내 직원 / 둘 다, 추천: 고객)
3) 만드는 쪽은? (보기: 사내 개발팀 / 외주 / 노코드로 직접, 추천: 사내 개발팀)

구성: 목적 / 사용자 이야기(누가, 무엇을, 왜) / 기능 요구사항 / 비기능 요구사항(속도, 보안 등) / 예외 상황 / 이번에 하지 않을 것. 정해지지 않은 부분은 [결정 필요]로 표시합니다.
