RECIPE 1 · 신사업/전략

신사업 아이템 발굴 및 임원용 원페이지 보고서

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 관심 산업/주제

순서

  1. 버튼 3 · 아이디어 도출

    실행할 수 있는 아이디어를 함께 찾겠습니다.

    프롬프트 보기
    실행할 수 있는 아이디어를 함께 찾겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 주제나 문제에 대한 아이디어가 필요한가요?
2) 누가 실행하나요? (보기: 나 혼자 / 작은 팀 / 회사 차원, 추천: 작은 팀)
3) 예산·기간 여유는? (보기: 거의 없음 / 보통 / 넉넉함, 추천: 보통)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
아이디어 5~10개를 표로 정리합니다. 컬럼: 아이디어 / 한 줄 설명 / 기대 효과 / 필요한 자원(사람·돈·시간, 대략). 마지막에 가장 먼저 해 볼 1개를 이유와 함께 추천합니다.

  2. 버튼 31 · SWOT 분석

    강점, 약점, 기회, 위협(SWOT)을 분석하겠습니다.

    프롬프트 보기
    강점, 약점, 기회, 위협(SWOT)을 분석하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 분석할까요? 회사, 제품, 계획 중 하나와 상황을 알려 주세요.
2) 비교 대상은? (보기: 주요 경쟁사 / 업계 평균 / 없음, 추천: 업계 평균)
3) 어디에 쓰나요? (보기: 전략 회의 / 보고서 / 내부 점검, 추천: 전략 회의)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
SWOT을 표로 정리하고 항목마다 근거를 한 줄씩 붙입니다. 그다음 강점·기회, 강점·위협, 약점·기회, 약점·위협을 묶은 실행 전략 4가지를 씁니다.

  3. 버튼 38 · 리스크 분석

    실행할 때 생길 수 있는 위험을 정리하겠습니다.

    프롬프트 보기
    실행할 때 생길 수 있는 위험을 정리하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 하려는지 알려 주세요. 계획이 있으면 붙여 넣어 주세요.
2) 특히 걱정되는 분야는? (보기: 일정 / 비용 / 법·규제 / 평판 / 전반, 추천: 전반)
3) 규모는? (보기: 작은 프로젝트 / 부서 단위 / 회사 전체, 추천: 부서 단위)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
위험을 표로 정리합니다. 컬럼: 위험 / 분류(운영, 재무, 법무, 평판) / 가능성(상중하) / 영향(상중하) / 미리 막는 방법 / 생겼을 때 대응. 가능성과 영향이 모두 높은 것을 위로 올립니다.

    원페이지 보고서를 함께 쓰겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.

2) 누구에게 보고하나요? (보기: 팀장 / 임원 / 대표, 추천: 임원)
3) 이 보고로 무엇을 받아야 하나요? (보기: 승인 / 의견 / 공유만, 추천: 승인)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
구성: 제목 / 보고 목적 / 핵심 요약 3줄 / 현황과 문제 / 추진 방안 / 기대 효과와 일정 / 요청 사항. 개조식으로 A4 한 장에 맞춥니다.
