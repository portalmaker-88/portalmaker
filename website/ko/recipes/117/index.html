RECIPE 117 · 인사/조직관리

사내 직무 교육 커리큘럼 설계 및 실습 사례 중심 강의 대본

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

    프롬프트 보기
    문서의 목차를 설계하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 문서인가요? 주제와 목적을 알려 주세요.
2) 누가 읽나요? (보기: 상사 / 임원 / 고객 / 팀원, 추천: 상사)
3) 분량은? (보기: 1~2쪽 / 5쪽 안팎 / 10쪽 이상, 추천: 5쪽 안팎)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
큰 제목, 중간 제목, 작은 제목으로 목차를 나누고 항목마다 들어갈 내용을 한 줄씩 씁니다. 결론이나 요청은 앞쪽에 둡니다.

1) 예시가 필요한 글을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 누가 읽나요? (보기: 실무자 / 처음 보는 사람 / 고객, 추천: 처음 보는 사람)
3) 우리 업종이나 상황은? (보기: 알려 주기 / 일반적인 예시로, 추천: 일반적인 예시로)

2) 청중과 발표 시간은? (보기: 내부 회의 10분 / 임원 보고 15분 / 외부 발표 30분, 추천: 내부 회의 10분)
3) 발표 후 청중이 무엇을 하길 바라나요? (보기: 승인 / 이해·공감 / 구매·계약, 추천: 승인)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
슬라이드마다 제목 / 핵심 메시지 한 문장 / 본문 불릿 2~4개 / 넣을 시각자료(표, 차트, 이미지). 장수는 발표 시간에 맞추고, 마지막 장에는 청중에게 요청할 행동을 넣습니다.
