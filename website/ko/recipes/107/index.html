RECIPE 107 · 일반사무/보고

사내 동향/업계 뉴스를 요약해 매주 공유하는 사내 뉴스레터

버튼 3개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 주간 업계 뉴스

순서

  1. 버튼 1 · 자료 요약

    받은 자료를 읽고 핵심을 정리하겠습니다.

    프롬프트 보기
    받은 자료를 읽고 핵심을 정리하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 요약할 자료를 붙여 넣어 주세요. (메일, 문서, 기사, 회의 메모 등 무엇이든 괜찮습니다)
2) 요약을 어디에 쓰나요? (보기: 내가 빨리 파악 / 상사에게 보고 / 팀에 공유, 추천: 내가 빨리 파악)
3) 길이는? (보기: 3줄 / 반 페이지 / 항목별 자세히, 추천: 3줄)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
핵심 요약 / 중요한 숫자와 날짜 / 내가 해야 할 일이나 답해야 할 것 / 자료에서 불분명한 점 순서로 정리합니다.

  2. 버튼 6 · 트렌드 분석

    주제와 관련된 흐름(트렌드)을 정리하겠습니다.

1) 어떤 분야나 주제의 트렌드가 궁금한가요?
2) 어디에 쓰나요? (보기: 기획 아이디어 / 보고 자료 / 개인 공부, 추천: 기획 아이디어)
3) 범위는? (보기: 국내 / 해외 / 둘 다, 추천: 둘 다)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
트렌드 3~5개를 정리합니다. 각각 무엇이 바뀌고 있는지 / 우리에게 주는 기회와 위험 / 확인할 자료. 검색 기능이 있으면 최신 출처 링크를 붙이고, 없으면 학습 시점 기준이라고 밝히고 구체적인 숫자는 [확인 필요]로 둡니다.

2) 독자는? (보기: 고객 / 사내 직원 / 업계 구독자, 추천: 고객)
3) 분위기는? (보기: 친근하게 / 전문적으로, 추천: 친근하게)

구성: 열고 싶은 제목 후보 2개 / 짧은 인사 / 핵심 소식이나 인사이트 2~4개 / 바로 써먹을 팁 / 마무리 질문이나 안내.
