RECIPE 142 · 문제해결/운영

법적 분쟁·컴플라이언스 위반 가능성 사전 차단 체크리스트

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 추진 중인 업무

  1. 버튼 49 · 법무/윤리점검

    법·윤리적으로 문제 될 부분을 점검하겠습니다.

    프롬프트 보기
    법·윤리적으로 문제 될 부분을 점검하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 점검할 글이나 계획을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 분야는? (보기: 광고·홍보 / 개인정보 / 계약·거래 / 저작권 / 전반, 추천: 전반)
3) 국가는? (보기: 한국 / 미국 / 기타(알려 주기), 추천: 한국)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
문제가 될 수 있는 표현이나 구조를 표로 짚습니다. 컬럼: 위치 / 이슈 / 관련 법이나 기준 / 안전한 대안. 법률 자문이 아니며 중요한 건은 전문가 확인이 필요하다고 밝힙니다.

    실행할 때 생길 수 있는 위험을 정리하겠습니다.

    프롬프트 보기
    실행할 때 생길 수 있는 위험을 정리하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 하려는지 알려 주세요. 계획이 있으면 붙여 넣어 주세요.
2) 특히 걱정되는 분야는? (보기: 일정 / 비용 / 법·규제 / 평판 / 전반, 추천: 전반)
3) 규모는? (보기: 작은 프로젝트 / 부서 단위 / 회사 전체, 추천: 부서 단위)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
위험을 표로 정리합니다. 컬럼: 위험 / 분류(운영, 재무, 법무, 평판) / 가능성(상중하) / 영향(상중하) / 미리 막는 방법 / 생겼을 때 대응. 가능성과 영향이 모두 높은 것을 위로 올립니다.

1) 누구와 어떤 일을 함께하나요? 거래 내용과 금액을 아는 만큼 알려 주세요.
2) 문서 종류는? (보기: 업무협약(MOU) / 용역 계약 / 구매 계약 / 기타, 추천: 용역 계약)
3) 우리 입장은? (보기: 일을 맡기는 쪽 / 맡는 쪽, 추천: 맡기는 쪽)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
항목별로 정리합니다: 목적 / 각자 할 일 / 기간 / 대금과 지급 조건 / 결과물 기준 / 비밀 유지 / 해지 / 손해 배상 / 분쟁 해결. 항목마다 우리에게 유리한 문구와 협상 포인트를 붙입니다. 법률 자문이 아니므로 서명 전에 전문가 검토가 필요하다고 밝힙니다.
