RECIPE 38 · 서비스/PM

프로덕트 팀 분기 OKR 설정 및 스프린트 백로그 우선순위화

버튼 3개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 제품 비전

순서

  1. 버튼 23 · 핵심지표설정

    성과를 잴 지표(KPI)를 정하겠습니다.

    프롬프트 보기
    성과를 잴 지표(KPI)를 정하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 일이나 프로젝트의 성과를 재려고 하나요? 목표도 알려 주세요.
2) 측정할 수 있는 데이터는? (보기: 매출·주문 / 방문·클릭 / 설문 / 거의 없음, 추천: 거의 없음)
3) 기간은? (보기: 월간 / 분기 / 연간, 추천: 분기)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
가장 중요한 지표 1개와 보조 지표 3~5개를 표로 정리합니다. 컬럼: 지표 / 계산 방법 / 미리 보여 주는 지표인지 결과 지표인지 / 측정 방법 / 목표 정하는 기준. 목표 숫자는 제가 준 기준이 없으면 [확인 필요]로 둡니다.

  2. 버튼 40 · 우선순위선정

    할 일의 우선순위를 정하겠습니다.

    프롬프트 보기
    할 일의 우선순위를 정하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 일들의 우선순위를 정할까요? 목록을 붙여 넣어 주세요. (이 대화에 앞선 목록이 있으면 그것을 씁니다)
2) 기준은? (보기: 효과 대비 노력 / 마감 / 비용, 추천: 효과 대비 노력)
3) 쓸 수 있는 자원은? (보기: 나 혼자 / 작은 팀 / 여유 있음, 추천: 작은 팀)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
각 항목을 효과와 노력으로 평가해 표로 정리하고, 빨리 끝낼 수 있는 것 / 크게 투자할 것 / 미룰 것 / 하지 않을 것으로 나눕니다. 이번 주에 시작할 1~3개를 추천합니다.

  3. 버튼 84 · OKR 수립

    목표와 핵심 결과(OKR)를 세우겠습니다.

    프롬프트 보기
    목표와 핵심 결과(OKR)를 세우겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 누구의 목표인가요? 팀이나 개인, 그리고 이루고 싶은 것을 알려 주세요.
2) 기간은? (보기: 분기 / 반기 / 연간, 추천: 분기)
3) 현재 수치가 있나요? (보기: 있음(알려 주기) / 없음, 추천: 없음)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
목표 1~3개와 목표마다 숫자로 확인할 핵심 결과 2~4개를 씁니다. 각 핵심 결과에 현재 값 / 목표 값 / 측정 방법 / 실행 과제를 붙입니다. 현재 값을 모르면 [측정 필요]로 둡니다.
