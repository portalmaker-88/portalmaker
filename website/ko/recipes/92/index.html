RECIPE 92 · 일반사무/보고

임원 주간/월간 보고용 발표자료(PPT) 및 예상 압박질문 방어

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 월간 실적/계획

순서

  1. 버튼 52 · 두괄식 재구성

    결론이 먼저 나오게(두괄식) 다시 구성하겠습니다.

    프롬프트 보기
    결론이 먼저 나오게(두괄식) 다시 구성하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 다시 구성할 글을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 누가 읽나요? (보기: 상사 / 임원 / 고객, 추천: 임원)
3) 형식은? (보기: 문단 / 개조식, 추천: 개조식)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
맨 위에 핵심 결론 한 문장, 그 아래 뒷받침하는 이유 2~4개와 세부 내용 순으로 바꿉니다. 내용은 빼거나 지어내지 않고 순서와 문장만 바꿉니다.

  2. 버튼 65 · PPT 슬라이드

    프롬프트 보기
    발표 자료 구성안을 함께 만들겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 발표하나요? 내용을 붙여 넣거나 주제와 핵심을 알려 주세요.
2) 청중과 발표 시간은? (보기: 내부 회의 10분 / 임원 보고 15분 / 외부 발표 30분, 추천: 내부 회의 10분)
3) 발표 후 청중이 무엇을 하길 바라나요? (보기: 승인 / 이해·공감 / 구매·계약, 추천: 승인)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
슬라이드마다 제목 / 핵심 메시지 한 문장 / 본문 불릿 2~4개 / 넣을 시각자료(표, 차트, 이미지). 장수는 발표 시간에 맞추고, 마지막 장에는 청중에게 요청할 행동을 넣습니다.

    발표 때 그대로 읽을 수 있는 대본을 쓰겠습니다.

2) 발표 시간은? (보기: 3분 / 10분 / 20분, 추천: 10분)
3) 말투는? (보기: 격식 있게 / 편안하게, 추천: 편안하게)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
슬라이드별로 나눠 말할 내용을 씁니다. 첫 30초 오프닝, 슬라이드 넘어갈 때 연결 멘트, 강조할 곳 표시([쉼], [강조]), 마지막 요청 멘트를 넣습니다. 분량은 1분에 300자 안팎으로 맞춥니다.

2) 누구 앞인가요? (보기: 임원 / 고객 / 투자자 / 심사위원, 추천: 임원)
3) 가장 걱정되는 부분이 있나요? (보기: 있음(알려 주기) / 없음, 추천: 없음)

예상 질문 5~7개를 씁니다. 각각 질문 뒤에 숨은 걱정 / 답변(30초 분량) / 답이 막힐 때 쓸 말을 붙입니다. 제가 준 내용에 없는 숫자로 답하지 않고, 필요하면 [준비할 자료]로 표시합니다.
