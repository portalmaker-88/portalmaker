RECIPE 156 · 데이터/자동화

시장 규모(TAM-SAM-SOM) 추정 로직 검증 및 엑셀 계산 시트

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 시장 분석 주제

1) 어떤 아이템의 시장인가요? 누구에게 파는지도 알려 주세요.
2) 지역은? (보기: 국내 / 특정 해외 / 글로벌, 추천: 국내)
3) 가진 숫자가 있나요? (보기: 있음(붙여 넣기) / 없음, 추천: 없음)

전체 시장 / 우리가 닿을 수 있는 시장 / 현실적으로 차지할 시장(TAM-SAM-SOM)을 계산식으로 보여 줍니다. 식에 들어가는 숫자마다 출처나 가정을 적고, 확인되지 않은 숫자는 [확인 필요: 어디서]로 표시합니다. 결과보다 계산 논리가 보이게 씁니다.

1) 점검할 글을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 누가 읽나요? (보기: 상사 / 임원 / 고객 / 투자자, 추천: 임원)
3) 얼마나 엄격하게? (보기: 큰 문제만 / 꼼꼼하게, 추천: 꼼꼼하게)

논리 비약, 모순, 근거 없는 가정을 표로 짚습니다. 컬럼: 위치 / 문제 / 왜 문제인지 / 고치는 방법. 그다음 고친 글을 보여 줍니다. 근거가 필요한 곳은 숫자를 지어내지 말고 [근거 필요]로 둡니다.

2) 우리가 가진 데이터가 있나요? (보기: 있음(붙여 넣기) / 없음, 추천: 없음)
3) 누가 읽나요? (보기: 내부 상사 / 임원 / 외부 고객·투자자, 추천: 내부 상사)

먼저 근거가 필요한 주장을 표로 정리합니다. 컬럼: 주장 / 필요한 근거 종류(내부 데이터, 공공 통계, 업계 보고서 등) / 확인할 곳 / 이미 있는 근거. 그다음 제가 준 숫자만 써서 본문을 보강하고, 없는 숫자는 [확인 필요: 무엇을, 어디서]로 남깁니다. 검색 기능이 있으면 출처 링크와 함께 찾아 주세요.
