1) 무슨 회의인가요? 목적과 꼭 다룰 내용을 알려 주세요.
2) 시간은? (보기: 30분 / 1시간 / 2시간, 추천: 1시간)
3) 참석자는? (보기: 우리 팀 / 여러 부서 / 외부 포함, 추천: 우리 팀)

구성: 회의 목적 / 안건별 시간 배분 / 안건별 논의할 점 / 회의가 끝날 때 정해야 할 것 / 미리 준비할 자료. 시간 합계가 회의 시간에 맞게 씁니다.
