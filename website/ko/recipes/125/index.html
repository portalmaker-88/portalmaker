RECIPE 125 · 인사/조직관리

인력 충원(Headcount) 승인을 받기 위한 경영진 설득 품의서

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 충원 필요 부서/사유

1) 어떤 업무 흐름인가요? 단계를 아는 만큼 알려 주세요.

3) 쓸 수 있는 도구는? (보기: 엑셀·구글시트 / 사내 시스템 / 자동화 도구, 추천: 엑셀·구글시트)

병목 구간 1~3곳을 찾아 이유를 씁니다. 각각 없애기 / 줄이기 / 자동화하기 방안을 붙이고, 바로 해 볼 수 있는 것부터 순서대로 놓습니다.

2) 알고 있는 금액이 있나요? (보기: 있음(알려 주기) / 총액만 / 없음, 추천: 없음)
3) 누구에게 승인받나요? (보기: 팀장 / 임원 / 외부 기관, 추천: 임원)

항목별 표로 정리합니다. 컬럼: 항목(인건비, 마케팅, 시스템, 예비비 등) / 금액 / 산정 근거(단가 × 수량) / 비고. 제가 주지 않은 금액은 만들지 말고 산정식만 쓴 뒤 [확인 필요]로 둡니다. 엑셀에 옮기기 쉽게 씁니다.

2) 우리가 가진 데이터가 있나요? (보기: 있음(붙여 넣기) / 없음, 추천: 없음)
3) 누가 읽나요? (보기: 내부 상사 / 임원 / 외부 고객·투자자, 추천: 내부 상사)

먼저 근거가 필요한 주장을 표로 정리합니다. 컬럼: 주장 / 필요한 근거 종류(내부 데이터, 공공 통계, 업계 보고서 등) / 확인할 곳 / 이미 있는 근거. 그다음 제가 준 숫자만 써서 본문을 보강하고, 없는 숫자는 [확인 필요: 무엇을, 어디서]로 남깁니다. 검색 기능이 있으면 출처 링크와 함께 찾아 주세요.
