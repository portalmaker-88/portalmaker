RECIPE 114 · 인사/조직관리

사내 조직문화 진단 설문조사 설계 및 개선 캠페인 기획

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 조직문화 고민

1) 지금 어떤 상황이고 무엇이 문제처럼 보이나요? 몇 줄로 알려 주세요.
2) 언제부터, 얼마나 자주 생기나요? (보기: 최근 시작 / 몇 달째 반복 / 잘 모름, 추천: 잘 모름)
3) 이 문제를 해결하면 누가 가장 좋아지나요? (보기: 나 / 우리 팀 / 고객 / 회사 전체, 추천: 우리 팀)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
보이는 현상과 근본 원인 후보를 나눠 표로 정리하고, 원인별로 확인할 방법을 붙입니다. 마지막에 우리가 답해야 할 핵심 질문 3개를 씁니다.

2) 문항 수는? (보기: 5개 안팎 / 10개 안팎 / 20개 안팎, 추천: 10개 안팎)

대상 확인 질문 / 핵심 질문(태도, 행동) / 자유 의견 순서로 씁니다. 문항마다 보기와 답 형식(객관식, 척도, 주관식)을 붙이고, 유도 질문이 되지 않게 씁니다. 결과를 어떻게 분석할지 2~3줄 덧붙입니다.

3) 주요 채널은? (보기: SNS / 오프라인 / 검색·광고 / 알아서, 추천: 알아서)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.

구성: 제목 / 한 줄 요약 / 안내 배경 / 핵심 내용(일시, 대상, 방법) / 유의사항 / 문의처. 중요한 날짜와 행동은 굵게 표시합니다. 정해지지 않은 정보는 [미정]으로 둡니다.
