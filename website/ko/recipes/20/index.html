    프롬프트 보기
    돈을 버는 구조(비즈니스 모델) 초안을 만들겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 아이템인가요? 누구에게 무엇을 파는지 알려 주세요.
2) 단계는? (보기: 아이디어 / 준비 중 / 이미 운영 중, 추천: 아이디어)
3) 판매 방식 선호가 있나요? (보기: 한 번 판매 / 구독 / 수수료 / 광고 / 잘 모름, 추천: 잘 모름)

수익원 / 가격 방식 / 주요 비용 / 필요한 파트너 / 고객을 데려오는 방법을 정리합니다. 가능한 모델 2개를 비교하고 하나를 추천합니다. 숫자는 제가 준 것만 쓰고, 나머지는 [확인 필요]로 둡니다.
