RECIPE 62 · 마케팅/브랜딩

고객 여정(인지-고려-구매-충성) 단계별 맞춤형 CRM 메시지 설계

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 서비스/상품

순서

  1. 버튼 15 · 고객 여정

    고객이 우리를 만나고 이용하는 과정(고객 여정)을 그려 보겠습니다.

    프롬프트 보기
    고객이 우리를 만나고 이용하는 과정(고객 여정)을 그려 보겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 제품이나 서비스인가요? 주요 고객도 알려 주세요.
2) 범위는? (보기: 처음 알게 된 때부터 구매까지 / 구매 후 재이용까지 / 전체, 추천: 전체)
3) 이미 아는 불편이 있나요? (보기: 있음(알려 주기) / 없음, 추천: 없음)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
단계별 표로 정리합니다. 컬럼: 단계 / 고객 행동 / 고객 생각과 감정 / 만나는 지점(앱, 매장, 상담 등) / 불편 / 개선 아이디어. 가장 먼저 고칠 지점 1~2개를 표시합니다.

  2. 버튼 18 · 카피 초안

    눈길을 끄는 헤드라인과 문구를 쓰겠습니다.

    프롬프트 보기
    눈길을 끄는 헤드라인과 문구를 쓰겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을, 누구에게 알리는 문구인가요?
2) 어디에 쓰나요? (보기: 광고 / 상세페이지 / SNS / 이메일 제목, 추천: SNS)
3) 톤은? (보기: 진지하게 / 친근하게 / 유쾌하게, 추천: 친근하게)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
헤드라인과 보조 문구를 짝지어 6~10개 씁니다. 호기심, 공감, 혜택 강조 등 접근을 섞고 각 문구 옆에 어떤 접근인지 표시합니다. 근거 없는 최고·1위 같은 표현은 쓰지 않습니다.

  3. 버튼 54 · 설득력 극대화

    상대가 동의하고 움직이게 설득력을 높이겠습니다.

    프롬프트 보기
    상대가 동의하고 움직이게 설득력을 높이겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 설득할 글을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 누구를 설득하나요? (보기: 상사 / 고객 / 다른 부서 / 투자자, 추천: 상사)
3) 원하는 행동은? (보기: 승인 / 구매 / 협조 / 회신, 추천: 승인)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
상대가 걱정할 점에 먼저 답하고, 근거(사례, 숫자, 다른 사람의 반응)를 앞쪽에 둡니다. 마지막에 원하는 행동을 분명하게 씁니다. 없는 근거는 지어내지 말고 [근거 추가]로 표시하며, 압박이나 과장은 쓰지 않습니다.

    업무 이메일을 함께 쓰겠습니다.

    업무 이메일을 함께 쓰겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 누구에게 무엇을 전하거나 요청하나요? 기한이 있으면 함께 알려 주세요.
2) 받는 사람과의 관계는? (보기: 상사 / 다른 부서 / 거래처·고객, 추천: 다른 부서)
3) 톤은? (보기: 정중 / 친근 / 단호, 추천: 정중)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
첫 두 줄 안에 용건과 요청을 쓰고, 요청에는 기한을 넣습니다. 제목 후보 2개와 본문 1개, 본문은 10줄 이내.
