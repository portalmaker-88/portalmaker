RECIPE 71 · 세일즈/CS

첫 영업 미팅(Discovery Call)을 주도하는 핵심 질문 리스트

버튼 3개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 고객사 산업/현황

순서

  1. 버튼 30 · 핵심배경요약

    처음 보는 사람도 이해하게 배경을 정리하겠습니다.

    프롬프트 보기
    처음 보는 사람도 이해하게 배경을 정리하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 주제의 배경이 필요한가요? 자료가 있으면 붙여 넣어 주세요.
2) 누가 읽나요? (보기: 나 / 신입·다른 부서 / 상사, 추천: 신입·다른 부서)
3) 분량은? (보기: 반 페이지 / 한 페이지 / 자세히, 추천: 한 페이지)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
핵심 용어 풀이 / 지금 상황 / 왜 지금 중요한지 / 더 알아볼 것 순서로 씁니다. 학습 시점 이후 바뀌었을 수 있는 내용은 그렇다고 표시합니다.

  2. 버튼 13 · 질문 리스트

    미팅이나 조사에 쓸 질문 목록을 만들겠습니다.

    프롬프트 보기
    미팅이나 조사에 쓸 질문 목록을 만들겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 누구에게, 무엇을 알아내려고 묻나요?
2) 자리 성격은? (보기: 고객 인터뷰 / 내부 회의 / 외부 미팅 / 설문 전 사전 조사, 추천: 고객 인터뷰)
3) 시간은? (보기: 15분 / 30분 / 1시간, 추천: 30분)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
현황 파악 / 문제 진단 / 앞으로의 방향 순서로 질문을 배치하고, 시간에 맞는 개수로 씁니다. 질문마다 왜 묻는지와 이어서 물을 꼬리 질문을 하나씩 붙입니다.

  3. 버튼 25 · 아젠다 도출

    회의 안건(아젠다)을 만들겠습니다.

    프롬프트 보기
    회의 안건(아젠다)을 만들겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무슨 회의인가요? 목적과 꼭 다룰 내용을 알려 주세요.
2) 시간은? (보기: 30분 / 1시간 / 2시간, 추천: 1시간)
3) 참석자는? (보기: 우리 팀 / 여러 부서 / 외부 포함, 추천: 우리 팀)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
구성: 회의 목적 / 안건별 시간 배분 / 안건별 논의할 점 / 회의가 끝날 때 정해야 할 것 / 미리 준비할 자료. 시간 합계가 회의 시간에 맞게 씁니다.
