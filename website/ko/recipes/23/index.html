RECIPE 23 · 서비스/PM

데이터 기반 그로스 해킹 가설 검증 및 KPI 대시보드 설계

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 서비스 지표 고민

순서

  1. 버튼 14 · 가설 설정

    검증할 수 있는 가설을 세우겠습니다.

    프롬프트 보기
    검증할 수 있는 가설을 세우겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 개선하거나 알아내고 싶나요? 지금 상황도 함께 알려 주세요.
2) 확인할 수 있는 데이터는? (보기: 매출·방문 데이터 / 설문 / 거의 없음, 추천: 거의 없음)
3) 검증 기간은? (보기: 1~2주 / 한 달 / 분기, 추천: 1~2주)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
가설 3~5개를 '만약 ~하면 ~가 될 것이다' 형식으로 씁니다. 각각 확인할 지표 / 성공 기준 / 가장 작은 실험 방법을 붙이고, 먼저 해 볼 것 1개를 추천합니다.

  2. 버튼 23 · 핵심지표설정

    성과를 잴 지표(KPI)를 정하겠습니다.

    프롬프트 보기
    성과를 잴 지표(KPI)를 정하겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 일이나 프로젝트의 성과를 재려고 하나요? 목표도 알려 주세요.
2) 측정할 수 있는 데이터는? (보기: 매출·주문 / 방문·클릭 / 설문 / 거의 없음, 추천: 거의 없음)
3) 기간은? (보기: 월간 / 분기 / 연간, 추천: 분기)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
가장 중요한 지표 1개와 보조 지표 3~5개를 표로 정리합니다. 컬럼: 지표 / 계산 방법 / 미리 보여 주는 지표인지 결과 지표인지 / 측정 방법 / 목표 정하는 기준. 목표 숫자는 제가 준 기준이 없으면 [확인 필요]로 둡니다.

  3. 버튼 42 · 수치/근거보강

    문서의 주장에 근거를 붙이겠습니다.

    프롬프트 보기
    문서의 주장에 근거를 붙이겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 근거를 보강할 글을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 우리가 가진 데이터가 있나요? (보기: 있음(붙여 넣기) / 없음, 추천: 없음)
3) 누가 읽나요? (보기: 내부 상사 / 임원 / 외부 고객·투자자, 추천: 내부 상사)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
먼저 근거가 필요한 주장을 표로 정리합니다. 컬럼: 주장 / 필요한 근거 종류(내부 데이터, 공공 통계, 업계 보고서 등) / 확인할 곳 / 이미 있는 근거. 그다음 제가 준 숫자만 써서 본문을 보강하고, 없는 숫자는 [확인 필요: 무엇을, 어디서]로 남깁니다. 검색 기능이 있으면 출처 링크와 함께 찾아 주세요.

    스프레드시트 구조와 수식을 만들겠습니다.

    프롬프트 보기
    스프레드시트 구조와 수식을 만들겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 관리하거나 계산하려고 하나요? 지금 쓰는 데이터 형태도 알려 주세요.
2) 프로그램은? (보기: 엑셀 / 구글 시트, 추천: 구글 시트)
3) 엑셀 실력은? (보기: 처음 / 기본 함수 / 익숙함, 추천: 기본 함수)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
열 설계표(열 이름, 데이터 종류, 예시 값)를 먼저 주고, 바로 복사해 쓸 수 있는 수식을 셀 위치와 함께 씁니다. 요약 표(피벗) 만드는 방법과 수식이 하는 일을 짧게 설명합니다.
