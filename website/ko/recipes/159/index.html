RECIPE 159 · 데이터/자동화

아이디어 마인드맵 구조화 및 Mermaid 마인드맵 코드 변환

버튼 3개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 브레인스토밍 주제

순서

  1. 버튼 3 · 아이디어 도출

    실행할 수 있는 아이디어를 함께 찾겠습니다.

    프롬프트 보기
    실행할 수 있는 아이디어를 함께 찾겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 어떤 주제나 문제에 대한 아이디어가 필요한가요?
2) 누가 실행하나요? (보기: 나 혼자 / 작은 팀 / 회사 차원, 추천: 작은 팀)
3) 예산·기간 여유는? (보기: 거의 없음 / 보통 / 넉넉함, 추천: 보통)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
아이디어 5~10개를 표로 정리합니다. 컬럼: 아이디어 / 한 줄 설명 / 기대 효과 / 필요한 자원(사람·돈·시간, 대략). 마지막에 가장 먼저 해 볼 1개를 이유와 함께 추천합니다.

  2. 버튼 35 · MECE 구조화

    내용을 겹치거나 빠지는 것 없이(MECE) 다시 묶겠습니다.

    프롬프트 보기
    내용을 겹치거나 빠지는 것 없이(MECE) 다시 묶겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 정리할 내용을 붙여 넣어 주세요. (이 대화에 앞선 답변이 있으면 그것을 씁니다)
2) 나누는 기준 선호가 있나요? (보기: 주제별 / 시간순 / 담당별 / 알아서, 추천: 알아서)
3) 결과 형태는? (보기: 번호 목록 / 표 / 트리 구조, 추천: 번호 목록)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
겹치는 항목은 합치고 빠진 항목은 [추가 제안]으로 표시해 다시 분류합니다. 위계가 보이게 번호를 붙이고, 어떤 기준으로 나눴는지 한 줄로 밝힙니다. 내용 자체는 바꾸지 않습니다.

  3. 버튼 90 · 시각화차트코드

    프롬프트 보기
    흐름이나 구조를 그림(다이어그램)으로 그리겠습니다.

[먼저 질문] 이 대화에 관련 내용이 아직 없다면 바로 쓰지 말고, 아래 질문을 한 번에 해 주세요. 대화에 이미 답이 있는 질문은 빼 주세요. 1번은 제가 직접 답하고, 2·3번에는 보기와 추천값을 붙여 주세요. 질문 끝에 "1번만 답하셔도 됩니다. 2·3번은 따로 말씀이 없으면 추천값으로 진행합니다."라고 안내해 주세요.
1) 무엇을 그림으로 보여 줄까요? 내용을 붙여 넣거나 알려 주세요.
2) 그림 종류는? (보기: 순서도 / 마인드맵 / 일정표(간트) / 조직도 / 알아서, 추천: 알아서)
3) 어디서 보나요? (보기: 머메이드를 지원하는 곳 / 그냥 글로 된 구조도, 추천: 머메이드를 지원하는 곳)

[작성] 답을 받으면 아래처럼 써 주세요. 제가 모른다고 한 부분은 가정을 밝히고 진행하고, 제가 주지 않은 숫자·사실은 만들지 말고 [확인 필요]로 표시해 주세요.
Mermaid 코드 블록으로 바로 그릴 수 있는 코드를 주고, 그 아래 같은 내용을 글로 된 구조도로도 씁니다. 코드를 그림으로 보는 방법(mermaid.live 등)을 한 줄로 안내합니다.
