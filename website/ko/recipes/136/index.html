RECIPE 136 · 문제해결/운영

외주 협력사(벤더) 선정 평가 기준표 및 표준 계약 조건 수립

버튼 4개를 차례로 복사해 같은 AI 대화창에 붙여넣으면 끝나요. AI가 질문하면 답한 뒤 다음 버튼으로 넘어가세요.

먼저 준비할 답

첫 버튼을 붙여넣으면 AI가 물어봐요. 이것만 알려 주면 돼요: 외주 발주 과업

구성: 목적 / 사용자 이야기(누가, 무엇을, 왜) / 기능 요구사항 / 비기능 요구사항(속도, 보안 등) / 예외 상황 / 이번에 하지 않을 것. 정해지지 않은 부분은 [결정 필요]로 표시합니다.
