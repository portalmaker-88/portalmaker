RECIPE 99 · Office / Reporting

Company Workshop / Townhall Plan, Host Script & Checklist

Copy 4 buttons in order and paste each into the same AI chat. When the AI asks questions, answer them, then move on to the next button.

Have this answer ready

After you paste the first button, the AI asks for this: Workshop Purpose

Steps

  1. Button 25 · Meeting Agenda

    Let's build a meeting agenda.

    See the prompt
    Let's build a meeting agenda.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What meeting is it? Tell me the goal and what must be covered.
2) Length? (options: 30 min / 1 hour / 2 hours; default: 1 hour)
3) Attendees? (options: my team / several departments / includes outsiders; default: my team)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Sections: Purpose / Time per item / Points to discuss per item / Decisions to make by the end / Materials to prepare. Make the times add up to the meeting length.

  2. Button 8 · Plan Draft

    Let's draft a plan together.

    See the prompt
    Let's draft a plan together.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What is the plan about? Tell me what you want to do and why in a line or two.
2) Who will read it and decide? (options: my manager / executives / an outside client; default: my manager)
3) Timeline and budget? (options: set (tell me) / not set yet; default: not set yet)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Sections: Background and purpose / Core content / Action plan (who, when, what) / Expected impact / Decisions needed.

  3. Button 66 · Speech Script

    Let's write a script you can read as you present.

    See the prompt
    Let's write a script you can read as you present.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What are you presenting? Paste the slide outline or content.
2) Length? (options: 3 min / 10 min / 20 min; default: 10 min)
3) Speaking style? (options: formal / relaxed; default: relaxed)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Split it by slide. Include a 30-second opening, transitions between slides, emphasis cues ([PAUSE], [EMPHASIS]), and a closing ask. Aim for about 130 words per minute.

  4. Button 82 · Checklist

    Let's build an execution checklist together.

    See the prompt
    Let's build an execution checklist together.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. 1) What is the checklist for? Paste the plan if you have one.
2) Who will use it? (options: me / my team / an outside partner; default: my team)
3) Any mistakes that happened before? (options: yes (tell me) / no; default: no)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
