RECIPE 93 · Office / Reporting

Rough Notes Expansion into Data-Backed Formal Report

Copy 4 buttons in order and paste each into the same AI chat. When the AI asks questions, answer them, then move on to the next button.

Have this answer ready

After you paste the first button, the AI asks for this: Brief Draft Notes

Steps

  1. Button 56 · Deep Expansion

    Let's expand a short draft with more depth and detail.

    See the prompt
    Let's expand a short draft with more depth and detail.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) Paste the text to expand. (If there is an earlier answer in this chat, I'll use that.)
2) What to strengthen? (options: background / how to execute / evidence and cases / all; default: how to execute)
3) Target length? (options: 1.5x / 2x / 3x; default: 2x)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Fill in why, how, who, and when for each item. Avoid repetition, and where facts or numbers are needed, do not invent them; mark [TO CONFIRM].

  2. Button 42 · Data Backing

    Let's back up the claims in a document with evidence.

    See the prompt
    Let's back up the claims in a document with evidence.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) Paste the text to strengthen. (If there is an earlier answer in this chat, I'll use that.)
2) Do you have your own data? (options: yes (paste it) / no; default: no)
3) Who will read it? (options: my manager / executives / outside clients or investors; default: my manager)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
First list the claims that need evidence in a table: Claim / Type of evidence needed (internal data, public statistics, industry reports, etc.) / Where to check / Evidence already available. Then strengthen the text using only numbers I gave, leaving [TO CONFIRM: what, where] for the rest. If you can search the web, find sources and include links.

  3. Button 43 · Case Examples

    Let's add concrete examples to abstract content.

    Let's add concrete examples to abstract content.

1) Paste the text that needs examples. (If there is an earlier answer in this chat, I'll use that.)
2) Who will read it? (options: practitioners / newcomers / customers; default: newcomers)
3) Your industry or situation? (options: I'll tell you / keep it general; default: keep it general)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Add a 'for example' scenario or a before-and-after for each point. Mark them [EXAMPLE] rather than presenting them as real company cases; cite real cases only when the source is certain.

    Let's write it as a formal report.

    Let's write it as a formal report.

1) What are you reporting? Paste the content or give the key points.
2) Style? (options: government style with hierarchy markers / corporate report style; default: government style)
3) Length? (options: 2 to 3 pages / about 5 pages / 10+ pages; default: 2 to 3 pages)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Sections: Background / Current analysis / Detailed plan / Resources needed / Expected outcomes. Use concise bullet statements with a consistent marker hierarchy (I, 1, A, •, -), and mark numbers I did not give [TO CONFIRM].
