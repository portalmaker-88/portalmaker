RECIPE 67 · Sales / CS

High-Win-Rate Custom B2B Proposal & ROI Justification

Copy 4 buttons in order and paste each into the same AI chat. When the AI asks questions, answer them, then move on to the next button.

Have this answer ready

After you paste the first button, the AI asks for this: Client Pain Point

Steps

  1. Button 4 · Problem Define

    Let's define the real problem to solve.

    See the prompt
    Let's define the real problem to solve.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What is the situation, and what looks like the problem? A few lines is enough.
2) Since when and how often? (options: recently started / repeating for months / not sure; default: not sure)
3) Who benefits most if it is solved? (options: me / my team / customers / the whole company; default: my team)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Separate the visible symptoms from candidate root causes in a table, with a way to check each cause. End with the 3 key questions we need to answer.

  2. Button 7 · Value Prop

    Let's pin down the core value you offer customers.

    See the prompt
    Let's pin down the core value you offer customers.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What do you offer, and to whom? One or two lines.
2) Main alternatives or competitors? (options: I'll tell you / not sure; default: not sure)
3) Where will this be used? (options: a plan / marketing copy / internal notes; default: a plan)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Match Customer problem / Our solution / Why it beats other options in a table, then write the value proposition in one sentence.

  3. Button 42 · Data Backing

    Let's back up the claims in a document with evidence.

    See the prompt
    Let's back up the claims in a document with evidence.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) Paste the text to strengthen. (If there is an earlier answer in this chat, I'll use that.)
2) Do you have your own data? (options: yes (paste it) / no; default: no)
3) Who will read it? (options: my manager / executives / outside clients or investors; default: my manager)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
First list the claims that need evidence in a table: Claim / Type of evidence needed (internal data, public statistics, industry reports, etc.) / Where to check / Evidence already available. Then strengthen the text using only numbers I gave, leaving [TO CONFIRM: what, where] for the rest. If you can search the web, find sources and include links.

  4. Button 64 · Biz Proposal

    Let's draft a proposal for a client or partner.

    See the prompt
    Let's draft a proposal for a client or partner.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) Who are you proposing to, and what? Tell me what you know about their situation.
2) What do they care about most? (options: cost / results / reliability / speed; default: results)
3) Length? (options: 1-page summary / about 5 pages / detailed; default: about 5 pages)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Sections: Their problem / Our solution / Why us / Plan and timeline / Expected results / Cost (if I gave it) / Next steps. Use result figures only when I gave a basis; otherwise mark [TO CONFIRM].
