RECIPE 140 · Ops / Problem Solving

Contrarian Workplace Innovation Ideas & Quick-Win 1-Pager

Copy 4 buttons in order and paste each into the same AI chat. When the AI asks questions, answer them, then move on to the next button.

Have this answer ready

After you paste the first button, the AI asks for this: Routine Field Work

Steps

  1. Button 9 · Reverse Idea

    Let's find ideas that flip the usual way of doing things.

    See the prompt
    Let's find ideas that flip the usual way of doing things.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What topic do you want to rethink? Tell me how it is usually done now.
2) How bold can it be? (options: realistic / fairly bold / completely new; default: fairly bold)
3) Any conditions that must hold? (options: yes (tell me) / no; default: no)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Find 3 to 5 assumptions people take for granted and write an idea that reverses each. For each idea add the expected benefit, the biggest risk, and a small way to test it.

  2. Button 3 · Idea Brainstorm

    Let's find ideas we can actually act on.

    See the prompt
    Let's find ideas we can actually act on.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What topic or problem do you need ideas for?
2) Who will carry them out? (options: just me / a small team / the whole company; default: a small team)
3) How much budget and time is there? (options: almost none / moderate / plenty; default: moderate)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Put 5 to 10 ideas in a table with columns: Idea / One-line description / Expected impact / Resources needed (people, money, time, rough). End by recommending the one to try first, with the reason.

  3. Button 40 · Priority Matrix

    Let's set priorities for the work.

    See the prompt
    Let's set priorities for the work.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What should I prioritize? Paste the list. (If there is an earlier list in this chat, I'll use that.)
2) Criteria? (options: impact vs. effort / deadline / cost; default: impact vs. effort)
3) Resources? (options: just me / a small team / plenty; default: a small team)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Rate each item on impact and effort in a table, then sort into Quick wins / Big bets / Later / Drop. Recommend 1 to 3 to start this week.

  4. Button 61 · 1-Page Report

    Let's write a one-page report together.

    See the prompt
    Let's write a one-page report together.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. 1) What are you reporting? Paste the content or give me the key points in a few lines.
2) Who is it for? (options: my manager / an executive / the CEO; default: an executive)
3) What do you need from it? (options: approval / feedback / just sharing; default: approval)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Sections: Title / Purpose / 3-line summary / Current status and issues / Action plan / Expected impact and schedule / Request. Use short bullet statements and fit one A4 page.
