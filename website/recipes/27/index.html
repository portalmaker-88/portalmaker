RECIPE 27 · Product / PM

Pre-Launch QA Inspection & Outage Contingency Plan

Copy 4 buttons in order and paste each into the same AI chat. When the AI asks questions, answer them, then move on to the next button.

Have this answer ready

After you paste the first button, the AI asks for this: Upcoming Release Features

Steps

  1. Button 20 · Req Definition

    Let's draft a requirements document for building this.

    See the prompt
    Let's draft a requirements document for building this.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What do you want to build? Describe the features and purpose.
2) Who will use it? (options: customers / internal staff / both; default: customers)
3) Who builds it? (options: in-house developers / an agency / myself with no-code; default: in-house developers)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Sections: Purpose / User stories (who, what, why) / Functional requirements / Non-functional requirements (speed, security, etc.) / Edge cases / Out of scope. Mark undecided items [DECISION NEEDED].

  2. Button 38 · Risk Matrix

    Let's list the risks of carrying this out.

    See the prompt
    Let's list the risks of carrying this out.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) Tell me what you plan to do. Paste the plan if you have one.
2) Main concern? (options: schedule / cost / legal and regulatory / reputation / all of it; default: all of it)
3) Scale? (options: small project / department level / company-wide; default: department level)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Risk table: Risk / Type (operational, financial, legal, reputational) / Likelihood (H/M/L) / Impact (H/M/L) / Prevention / Response if it happens. Put high-likelihood, high-impact risks at the top.

  3. Button 48 · Plan B Setup

    Let's prepare scenarios for when things change.

    See the prompt
    Let's prepare scenarios for when things change.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What plan is it? Paste or summarize it.
2) Biggest uncertainty? (options: market and demand / cost / schedule / staffing; default: market and demand)
3) Which goal must hold? (options: revenue / schedule / quality; default: schedule)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Write 3 scenarios: good / base / bad. For each: the signals that tell you it is happening / what changes / your response (Plan B).

  4. Button 82 · Checklist

    Let's build an execution checklist together.

    See the prompt
    Let's build an execution checklist together.

[Ask first] If this chat has no relevant content yet, do not start writing. Ask the questions below in one message, leaving out any already answered in this chat. Question 1 is open for me to answer; give questions 2 and 3 options and a suggested default. End with "You only need to answer question 1. Unless you say otherwise, I'll use the defaults for 2 and 3."
1) What is the checklist for? Paste the plan if you have one.
2) Who will use it? (options: me / my team / an outside partner; default: my team)
3) Any mistakes that happened before? (options: yes (tell me) / no; default: no)

[Write] Once I answer, write it as follows. Where I say I don't know, state your assumption and continue. Do not invent numbers or facts I did not give; mark them [TO CONFIRM].
Split it into Prepare / Execute / Wrap up, and give each item a checkbox (□) and a done criterion (what counts as finished). Include only as many items as are needed.
